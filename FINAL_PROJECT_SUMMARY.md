## 📊 **TECHNICAL SPECIFICATIONS**

### **Backend Architecture**
- **Framework**: Node.js + Express.js
- **Database**: PostgreSQL with Sequelize ORM
- **Authentication**: JWT (JSON Web Tokens)
- **Security**: bcryptjs, CORS, Helmet, Rate Limiting
- **File Upload**: Multer (ready for implementation)
- **API**: RESTful endpoints with proper error handling

### **Frontend Architecture**
- **Framework**: React 18 + JavaScript ES6+
- **Routing**: React Router with protected routes
- **State Management**: Context API (Auth, Language)
- **Styling**: Tailwind CSS with responsive design
- **Internationalization**: i18next with English/French support
- **Security**: PrivateRoute, ErrorBoundary, Loading components

### **Database Schema**
- **Users**: Complete user management with roles
- **Courses**: Full course structure with lessons and modules
- **Organizations**: Organization management system
- **Certificates**: Certificate generation and tracking
- **Affiliates**: Referral and commission system
