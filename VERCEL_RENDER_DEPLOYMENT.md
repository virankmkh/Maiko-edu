## 🚀 **Step-by-Step Deployment**

### **Phase 1: Deploy Backend to Render**

#### **Step 1: Prepare Backend**
1. **Go to [render.com](https://render.com)**
2. **Sign up with GitHub account**
3. **Click "New +" → "Web Service"**

#### **Step 2: Connect Repository**
1. **Select "Build and deploy from a Git repository"**
2. **Connect your GitHub account**
3. **Select `Maiko-edu` repository**
4. **Choose "Deploy"**

#### **Step 3: Configure Backend Service**
```
Name: maiko-edu-backend
Environment: Node
Build Command: npm install
Start Command: npm start
Root Directory: server
```

#### **Step 4: Add Environment Variables**
```
NODE_ENV=production
PORT=10000
CLIENT_URL=https://your-domain.vercel.app
DATABASE_URL=[Auto-generated by Render]
JWT_SECRET=your-super-secure-jwt-secret-key-here
PAYPAL_CLIENT_ID=your-paypal-client-id
PAYPAL_CLIENT_SECRET=your-paypal-client-secret
PAYPAL_MODE=live
JITSI_APP_ID=your-jitsi-app-id
JITSI_PRIVATE_KEY=your-jitsi-private-key
H5P_LIBRARY_PATH=/h5p/libraries
H5P_CONTENT_PATH=/h5p/content
H5P_TEMP_PATH=/h5p/temp
MATOMO_URL=https://your-matomo-instance.com
MATOMO_SITE_ID=1
CORS_ORIGIN=https://your-domain.vercel.app
```

#### **Step 5: Add PostgreSQL Database**
1. **Click "New +" → "PostgreSQL"**
2. **Name: maiko-edu-db**
3. **Plan: Free (or Starter for $7/month)**
4. **Copy the DATABASE_URL** to your backend environment variables

#### **Step 6: Deploy Backend**
1. **Click "Create Web Service"**
2. **Wait for deployment** (5-10 minutes)
3. **Copy your backend URL** (e.g., `https://maiko-edu-backend.onrender.com`)

---

### **Phase 2: Deploy Frontend to Vercel**

#### **Step 1: Prepare Frontend**
1. **Go to [vercel.com](https://vercel.com)**
2. **Sign up with GitHub account**
3. **Click "New Project"**

#### **Step 2: Import Repository**
1. **Select `Maiko-edu` repository**
2. **Vercel auto-detects React app**
3. **Configure build settings:**

```
Framework Preset: Create React App
Root Directory: client
Build Command: npm run build
Output Directory: build
Install Command: npm install
```

#### **Step 3: Add Environment Variables**
```
NODE_ENV=production
REACT_APP_API_URL=https://maiko-edu-backend.onrender.com
REACT_APP_CLIENT_URL=https://your-domain.vercel.app
```

#### **Step 4: Deploy Frontend**
1. **Click "Deploy"**
2. **Wait for build** (2-3 minutes)
3. **Get your Vercel URL** (e.g., `https://maiko-edu.vercel.app`)

---

### **Phase 3: Configure Custom Domain**

#### **Step 1: Update Backend CORS**
1. **Go to Render dashboard**
2. **Edit environment variables**
3. **Update CORS_ORIGIN to your custom domain**

#### **Step 2: Configure Vercel Domain**
1. **Go to Vercel dashboard**
2. **Click on your project**
3. **Go to "Domains" tab**
4. **Add your custom domain**
5. **Vercel provides DNS instructions**

#### **Step 3: Configure Namecheap DNS**
1. **Login to Namecheap**
2. **Go to Domain List → Manage**
3. **Set DNS records:**

```
Type: CNAME
Host: www
Value: cname.vercel-dns.com
TTL: Automatic

Type: A
Host: @
Value: 76.76.19.61
TTL: Automatic
```

#### **Step 4: Update Frontend Environment**
1. **Go to Vercel dashboard**
2. **Update environment variables:**
```
REACT_APP_CLIENT_URL=https://your-domain.com
```

## 🆘 **Troubleshooting**

### **Common Issues:**

1. **Build Fails on Vercel**
   - Check Node.js version (18+)
   - Verify all dependencies in package.json
   - Check build logs for specific errors

2. **Backend Not Starting on Render**
   - Verify PORT environment variable
   - Check database connection
   - Review server logs

3. **Domain Not Working**
   - Wait 24-48 hours for DNS propagation
   - Check DNS records in Namecheap
   - Verify CORS settings

4. **API Calls Failing**
   - Check CORS configuration
   - Verify API URLs in environment variables
   - Check network tab in browser
